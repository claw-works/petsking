agent-pet

一个渲染无关、驱动可插拔、程序与素材分离的桌面宠物库。
同一套 API，六种渲染载体，两种驱动方式，一键接入 AI / Agent 事件。

🎛️ 浏览 Instances 🎮 打开 Playground 📖 库文档

四层解耦架构

驱动决定「播什么」，渲染决定「怎么画」，素材决定「画什么」，AI 层归一化外部事件。

🎲 驱动 Driver
chain 概率链（自主）/ statemachine 状态机（Agent 事件→语义状态）
🖼️ 渲染 Renderer
webm / gif / 精灵表 / 像素 / SVG / Three.js 六种，统一接口
📦 素材 AssetPack
pets/<id>/pet.json + 素材文件，与程序完全分离
🤖 AI 接入
Agent 事件归一化 + 意图/情绪表演 + 可选 LLM 决策
