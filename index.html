Architecture

四层解耦架构

驱动决定「播什么」，渲染决定「怎么画」，素材决定「画什么」，AI 层归一化外部事件——每一层都可独立替换。

01
🎲 驱动 Driver
chain 概率链（自主陪伴）/ statemachine 状态机（Agent 事件 → 语义状态）
02
🖼️ 渲染 Renderer
webm / gif / 精灵表 / 像素 / SVG / Three.js 六种载体，统一接口
03
📦 素材 AssetPack
pets/<id>/pet.json + 素材文件，与程序完全分离，换宠物只换一个 json
04
🤖 AI 接入
Agent 事件归一化 + 意图/情绪表演 + 可选 LLM 决策

Drivers

两种驱动范式

决定宠物「下一个动作播什么」的两套逻辑。

概率动画链（chain）

加权掷骰在动作池间衔接，自主陪伴，不看外部信号。适合装饰型桌宠。

Quickstart

一行接入

纯 ESM，无需构建工具。静态服务器托管即可运行。

index.html
// 一行，桌宠出现在右下角
import { createPet } from './pet-lib/index.js';
const pet = await createPet({ pet: 'blue-whale' });

// 接 Agent：反映 AI 工作状态
pet.feed({ type: 'agent.thinking' });
pet.react('happy');
pet.say('搞定啦～');
