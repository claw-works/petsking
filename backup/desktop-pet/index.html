🖥️ dsh-desktop-pet 复刻

范式：确定性语义状态机。事件→状态是纯函数分类（无随机），10 个 SemanticState 折叠到 6 个动画姿势。原版是原生透明窗口 + sprite sheet 逐帧，这里用 webm 表达同一套状态逻辑。

亮点：多任务优先级折叠——多个 Agent 并发时取最高优先级（WAITING_FOR_USER > ERROR > WORKING > THINKING > SUCCESS > IDLE）。flash 态 2s 回落，静默 12s 自动 SLEEPING。

命令框支持 /pet 式输入：直接敲 THINKING / ERROR / RESET。

模拟归一化事件（单任务 default）
